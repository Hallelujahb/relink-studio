## How to be listed

Open a pull request that gets merged and add yourself to the table above in the same PR (or ask a maintainer to add you). Every kind of contribution counts:

- **Code.** Fixes, features, new matching methods
- **Docs.** README, guides, examples, translations
- **Bug reports.** Clear reports with a small anonymized sample
- **Testing.** Trying it on real data and reporting what you learned
- **Design.** UI and workflow improvements
- **Review.** Reviewing pull requests

Use this row format:

```
| Your Name | [@username](https://github.com/username) | Code, Docs |
```
